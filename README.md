🌐 Portafolio Web



🚀 Sobre el Proyecto

Este es mi portafolio web donde muestro mi experiencia y habilidades en pruebas automatizadas utilizando herramientas como Playwright, Cypress y Selenium. Aquí encontrarás ejemplos de tests, buenas prácticas y proyectos en los que he trabajado.

📌 Tecnologías Utilizadas

🖥️ HTML, CSS y JavaScript – Para la estructura y el diseño del portafolio.

⚙️ Playwright – Para pruebas de automatización de extremo a extremo.

🌲 Cypress – Para pruebas funcionales y de integración.

🐍 Selenium – Para pruebas en múltiples navegadores.

💡 GitHub Actions – Para integración continua y ejecución automática de tests.
